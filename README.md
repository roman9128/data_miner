# Telegram Data Miner

**Telegram Data Miner** — приложение для сбора, обработки и интеллектуального анализа данных из Telegram.

Приложение позволяет собрать сообщения из выбранных каналов и папок, автоматически обработать их и сохранить в структурированном виде в локальной базе данных.

После сбора данных доступны два основных сценария:

* **создать датасет в CSV** и использовать его для дальнейшего анализа в BI-системах и других инструментах;
* **исследовать данные непосредственно в приложении с помощью встроенного ИИ-агента**.

Таким образом, Data Miner объединяет сбор данных, их подготовку и последующий анализ в одном приложении.

## 📥 Сбор данных

Приложение позволяет:

* подключиться к Telegram;
* выбрать каналы и папки;
* указать период сбора;
* загрузить историю сообщений;
* сохранить собранные данные в локальной базе.

Сообщения автоматически обрабатываются и дополняются дополнительными признаками: темами, сущностями, ключевыми словами и статистикой текста.

## 📊 Подготовка датасетов

Data Miner можно использовать как инструмент подготовки данных для последующего анализа.

Собранную информацию можно экспортировать в **CSV** и использовать в:

* Power BI;
* Tableau;
* Excel;
* других BI- и аналитических системах;
* собственных инструментах обработки данных.

Это позволяет использовать Telegram как источник данных для создания собственных отчётов, графиков и аналитических моделей.

## 🤖 Исследование данных с помощью ИИ

Вместо экспорта данных пользователь может сразу перейти к их исследованию с помощью встроенного **ИИ-агента**.

Агент работает с собранной базой и может находить нужную информацию среди большого количества сообщений.

Вопросы можно задавать обычным языком:

> Какие темы чаще всего обсуждались за последний месяц?

> Найди сообщения, связанные с ростом цен.

> Что писали о компании X?

> Какие события чаще всего обсуждались в выбранных каналах?

Для поиска используется **семантический поиск**. Поэтому необязательно знать точные слова, которые встречались в исходных сообщениях — система ищет информацию по смыслу.

## 🎯 Контекст анализа

При работе с ИИ можно ограничить область исследования:

* конкретными каналами;
* периодом;
* темами;
* именованными сущностями.

Например, можно выбрать один канал и последние 30 дней, а затем попросить ИИ проанализировать происходившее за этот период.

Это особенно полезно при работе с большими базами, где анализировать все собранные данные одновременно не требуется.

## 🔄 Два способа работы с данными

```text
                    Telegram
                       ↓
                 Сбор данных
                       ↓
             Обработка сообщений
                       ↓
                Локальная база
                  ↙         ↘
                 ↙           ↘
              CSV             ИИ-агент
               ↓                ↓
        BI / аналитика      Исследование
                              данных
```

**Классический анализ**

Собрать данные → экспортировать CSV → загрузить в BI-систему → построить собственную аналитику.

**Интеллектуальный анализ**

Собрать данные → задать вопрос ИИ → найти нужные сообщения → получить их анализ.

Эти подходы могут использоваться независимо или дополнять друг друга.

## 💡 Для чего подходит Data Miner

Приложение может использоваться для:

* анализа Telegram-каналов;
* изучения информационной повестки;
* поиска сообщений по смыслу;
* исследования публикаций за определённый период;
* подготовки датасетов для BI и аналитики;
* работы с большими объёмами Telegram-данных;
* быстрого исследования собранной информации с помощью ИИ.

## 🔐 Локальное хранение

Основная база данных хранится **локально**. Это позволяет сохранять и повторно использовать собранные данные, экспортировать их и самостоятельно определять, какие данные использовать для дальнейшего анализа.

ИИ-агент работает не со всей базой целиком, а получает необходимые данные через инструменты поиска и анализа.

## Статус

Проект находится в активной разработке.

Основная идея проекта — создать единый инструмент, который позволяет пройти весь путь от получения информации до её анализа:

> **Собрать → структурировать → экспортировать или исследовать с помощью ИИ.**
