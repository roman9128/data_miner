# Telegram Data Miner

**Telegram Data Miner** — desktop-приложение на Java для сбора и анализа сообщений из Telegram.

Приложение подключается к Telegram через **TDLib**, загружает историю каналов и последовательно обрабатывает сообщения, извлекая структурированные данные для дальнейшего анализа и BI.

## Возможности

### Telegram

* авторизация через Telegram;
* получение каналов и папок;
* выбор канала, папки и диапазона дат;
* загрузка истории сообщений;
* получение ссылок на сообщения;
* поддержка различных типов сообщений.

### Анализ текста

Для сообщений выполняется:

* статистический анализ текста;
* подсчёт слов и символов;
* анализ emoji;
* выделение существительных;
* NER — распознавание именованных сущностей;
* определение тематик;
* расчёт confidence для тематик.

Результаты анализа сохраняются вместе с данными сообщения.

## Архитектура

Основной pipeline:

```text
Telegram
   │
   ▼
История сообщений
   │
   ▼
Message Queue
   │
   ▼
DataService
   │
   ├── Text Statistics
   ├── Nouns
   ├── NER
   └── Topics
   │
   ▼
SQLite
   │
   ▼
Dataset / BI
```

Загрузка сообщений и их обработка разделены через очередь. Это позволяет обрабатывать большие объёмы данных последовательно и не держать всю историю канала в памяти.

---

## Хранение данных

Основное хранилище — **SQLite**.

Данные разделены на несколько связанных сущностей:

* сообщения;
* существительные;
* именованные сущности;
* синонимы и теги сущностей;
* тематики;
* связи сообщений с сущностями и тематиками.

В результате сообщение превращается в структурированный набор данных:

```text
Message
 ├── Telegram metadata
 ├── Text
 ├── Statistics
 ├── Nouns
 ├── Named Entities
 └── Topics + confidence
```

Такой формат позволяет использовать полученные данные для анализа каналов, поиска закономерностей и построения BI-отчётов.

* **TDLight Java / TDLib**
* **SQLite**
* **Apache OpenNLP**
* **Demidko AOT**
* **Jackson**
* **Maven**
* **Docker**

NLP-модели и дополнительные словари находятся в каталоге:

```text
nlp_models/
```

Именованные сущности (NER) находятся в каталоге:

```text
ne_json/
```
