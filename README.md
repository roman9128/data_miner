# Telegram Data Miner

**Telegram Data Miner** — настольное приложение для подготовки информативных датасетов на основании постов из Telegram-каналов.

Программа подключается к Telegram, получает историю выбранных каналов, папок и периодов, последовательно обрабатывает сообщения и сохраняет исходные данные вместе с результатами текстового анализа в **SQLite**.

Главная задача проекта — **не заменить поиск, BI или специализированную аналитическую систему**, а подготовить для них качественный и обогащённый набор данных.

> **Telegram → сбор данных → обогащение → датасет**

---

## Зачем нужен Data Miner

Telegram содержит большое количество неструктурированной информации. Само по себе наличие истории сообщений ещё не означает, что с ней удобно работать.

Data Miner выполняет предварительную обработку:

- собирает сообщения из выбранных источников;
- сохраняет информацию о сообщении и его источнике;
- считает базовую статистику текста;
- выделяет существительные;
- распознаёт именованные сущности;
- определяет тематики;
- сохраняет вероятность соответствия текста сообщения тематике (confidence) для тематической классификации;
- связывает результаты анализа с исходными сообщениями.

В результате получается датасет, который можно использовать дальше в специализированных инструментах:

- поисковых системах;
- BI;
- SQL-анализе;
- Python / Pandas;
- машинном обучении;
- собственных аналитических приложениях.

Data Miner намеренно не пытается заменить эти инструменты.

---

## Основной принцип

**Собрать данные один раз — использовать их дальше там, где это удобно.**

Сейчас основной результат работы — локальная база SQLite.

## Что собирается

### Telegram

Приложение позволяет:

- авторизоваться в Telegram;
- получать и выбирать доступные каналы и папки;
- задавать диапазон дат;
- загружать историю сообщений;
- получать ссылки на сообщения;
- обрабатывать разные типы сообщений.

### Данные сообщения

В датасете сохраняются, в частности:

- идентификатор сообщения;
- идентификатор канала;
- название канала;
- ссылка на сообщение;
- дата публикации;
- тип содержимого;
- текст;
- статистика текста.

---

## Обогащение текста

Для сообщений выполняется дополнительный анализ.

### Статистика

Сохраняются характеристики текста, включая:

- количество слов;
- количество символов;
- emoji;
- другие базовые показатели.

### Существительные

Выделяются существительные, которые могут использоваться как дополнительные признаки сообщения.

### Распознавание именованных сущностей (Named Entity Recognition, NER)

NER используется для обнаружения именованных сущностей.

Для проекта также предусмотрены собственные JSON-словари сущностей, синонимов и тегов, которые пользователь может наполнять по своему усмотрению.

### Тематическая классификация

Сообщения могут классифицироваться по заранее подготовленным собственным тематическим моделям.

Для каждой найденной темы сохраняется значение **confidence**, позволяющее использовать результат не только как жёсткую категорию, но и как вероятностный признак.

## Pipeline

Основной процесс выглядит так:

```text
Telegram
   │
   ▼
Каналы / папки / период
   │
   ▼
История сообщений
   │
   ▼
Очередь обработки
   │
   ▼
Анализ сообщения
   │
   ├── Статистика
   ├── Существительные
   ├── Именованные сущности
   └── Тематики + confidence
   │
   ▼
SQLite
   │
   ▼
Готовый датасет
```

Загрузка и обработка сообщений разделены очередью. Сообщения обрабатываются последовательно, поэтому приложение не держит всю загруженную историю в оперативной памяти.

---

## Почему локальная обработка

Data Miner задуман прежде всего как локальный инструмент.

Это позволяет:

- хранить собранные данные на своём компьютере;
- не отправлять всю историю каналов в сторонний аналитический сервис;
- самостоятельно выбирать объём и источники данных;
- повторно использовать полученный датасет;
- экспериментировать с методами обработки текста.

---

## Хранение

Основное хранилище — **SQLite**.

Структура базы связывает сообщения с результатами их обработки:

```text
Message
 ├── Telegram metadata
 ├── Text
 ├── Statistics
 ├── Nouns
 ├── Named Entities
 └── Topics + confidence
```

Такой подход позволяет сохранять не только исходный текст, но и дополнительные признаки, которые затем можно использовать независимо от интерфейса Data Miner.

## Что является результатом работы

Результат Data Miner — не поисковая выдача и не готовый аналитический отчёт.

Результат — **подготовленный датасет**.

Например:

```text
Сообщение
 ├── источник
 ├── дата
 ├── текст
 ├── ссылка
 ├── статистика
 ├── существительные
 ├── именованные сущности
 └── тематики с confidence
```

Такой датасет можно затем передать в другой инструмент, который лучше подходит для конкретной задачи.

Например:

```text
Data Miner
    │
    ▼
Dataset
    │
    ├── Search
    ├── BI
    ├── ML
    ├── Python
    └── собственное приложение
```

---

## Что Data Miner не пытается делать

Проект сознательно не является:

- универсальным поисковиком Telegram;
- системой мониторинга брендов;
- готовой BI-платформой;
- конечной системой аналитики;
- заменой специализированным поисковым и аналитическим инструментам.

Его задача проще:

> **получить из Telegram как можно более полезный и информативный набор данных для дальнейшей работы.**

---

## Статус проекта

Проект находится в активной разработке.

Основное направление развития — повышение качества и информативности получаемого датасета.

Приоритет имеет сохранение полезной информации на этапе сбора и добавление действительно ценных признаков при обработке текста.
